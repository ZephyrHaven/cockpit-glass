# Theme screenshots

Original macOS screenshots supplied by the project maintainer and displayed in both root READMEs:

| File | Appearance |
| --- | --- |
| `cockpit-glass-light.png` | Light mode |
| `cockpit-glass-dark.png` | Dark mode |

The images are preserved without editing. The Cockpit tab and AI shortcut visible in the screenshots belong to the optional Cockpit Dashboard plugin.

The community listing currently uses `screenshots/cockpit-glass-dark.png`, configured as `communityScreenshot` in `theme.config.json`. Keep the listing form and this setting aligned. The screenshot must be committed before creating the release tag; the community scanner checks that release revision. A future dedicated store card may use the recommended 512×288 ratio.

The synthetic browser fixtures in ignored `output/playwright/` are for regression checks only and must not be submitted as real application screenshots.
