# Cockpit Glass 1.3.3 验证记录

日期：2026-11-08。

## 本次范围

- 移除左侧独有的渐变色层、底色和工具托盘，整个原生玻璃窗口共享一层静态淡色背景。
- 降低静止分割线存在感，保留原生拖动命中范围、光标和悬停/拖动反馈。
- 文件树使用更轻的字重和更紧凑的间距；按钮通过短颜色过渡回应操作，移除按压缩放。
- 增加独立阅读样式模块：正文宽度、行高、标题/段落节奏、引用、列表、链接、表格和代码块；不强制打开缩减栏宽，也不改变编辑器布局。
- 背景 Motion 暂缓。本版不加入持续背景动画、新滤镜、额外渲染叠层或滚动容器变换。

## 已通过的检查

- `npm test`：构建和源码约束校验通过，14 项工程测试通过。覆盖确定性构建、备份、回滚、目录锁、外部修改保护和无关文件保留。
- `npm run build:check`：生成产物与源码一致。
- `npm run release:check`：版本、ZIP 内容及校验和检查通过。此命令仅校验产物，不执行 GitHub Release 发布或社区目录提交。
- `PLAYWRIGHT_BROWSERS_PATH=/private/tmp/cockpit-glass-playwright npm run test:ui`：151 项浏览器检查通过，使用本机宿主 CSS 和 Chromium。
- `git diff --check`：通过。
- `bash deploy.sh`：已部署到本机配置的主题目录，旧版已备份至该目录下的 `.cockpit-backups/`。部署后逐字节比对已安装的 CSS、清单与已验证产物，一致。

浏览器回归覆盖深浅色、阅读/源码/实时预览透明背景、两侧无独立底色、分割线反馈、窄分栏控件、长文与文件树独立滚动、搜索和侧栏状态变化后阅读位置保留、文本选择、窄窗口无整页横向溢出、代码换行偏好、键盘焦点、拖拽/重命名状态、RTL、移动触控目标、减少动态效果、减少透明度与强制颜色。

窗口、侧栏和阅读滚动容器的 transform、scale、filter、backdrop-filter、will-change、contain、isolation 均与未加载主题的宿主 CSS 比较，未增加合成相关覆盖；页面未出现无限循环动画。这些检查不等同于 GPU/原生窗口合成验收。

合成阅读容器的内联宽高依据本机应用运行时构造逻辑补齐；旧测试页面没有该高度约束，无法正确代表长文滚动。代码块回归发现并移除了会覆盖宿主换行偏好的 text-wrap 声明。

## 视觉检查与限制

已检查深浅色桌面及窄窗口合成截图。截图位于忽略的 `output/playwright/`，使用虚构笔记与人工背景；不包含用户笔记或真实系统毛玻璃效果，不替换社区截图。

真实 Obsidian 的界面捕捉被系统 `SCStreamErrorDomain -3811` 阻断。本次无法完成原生玻璃下的快速滚动、切换、窗口缩放与残影验收，不能据浏览器检查承诺实机没有残影、重绘异常或卡顿。为遵循稳定性优先的要求，持续背景动效不进入本次部署。
